# MCP-powered Agentic RAG

🚀 **Demo of an Agentic RAG powered by MCP**  
This project showcases a Retrieval-Augmented Generation (RAG) system powered by **Multi-Agent Collaborative Planning (MCP)**.

🎥 **Demo Overview**  
An MCP-driven Agentic RAG that searches a vector database and falls back to web search if needed.

---

## 🧠 What's Inside?

This Agentic RAG intelligently handles queries using the following logic:

- Retrieves relevant context from a **vector database**
- If insufficient information is found, it **falls back to web search**
- Coordinates multiple steps and reasoning using **MCP agents**

---

## 🛠️ Tech Stack

| Component        | Purpose                                       |
|------------------|-----------------------------------------------|
| **MCP**          | Multi-Agent Collaborative Planning for goal decomposition and task orchestration |
| **Bright Data**  | Web scraping at scale for fallback search     |
| **Qdrant**       | High-performance vector database for semantic search |
